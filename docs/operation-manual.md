# BidPivot 操作手册

> 极智标枢 - 标书智造平台

## UI 框架说明

BidPivot 前端采用 **Ant Design Vue** 作为 UI 组件库，配合 **Vben Admin** 布局框架构建。整体界面风格统一，包含以下核心 UI 组件：

- **布局**：Vben Admin 提供的侧边栏导航 + 顶部导航栏 + 面包屑 + 内容区域布局
- **表单**：Ant Design Vue 的 AForm / AInput / ASelect 等表单组件
- **表格**：ATable / APagination 数据表格组件
- **弹窗**：AModal / AModal.confirm / message 消息提示组件
- **按钮**：AButton 统一按钮样式（primary / default / dashed / text）
- **菜单**：AMenu 侧边栏导航菜单

## 1. 用户注册与登录

### 功能说明

BidPivot 采用手机号 + 图形验证码的方式进行登录和注册。首次登录的用户会自动创建账号。系统支持图形验证码防爆破机制，保障账户安全。

### 操作步骤

1. 打开 BidPivot 首页，点击右上角 **登录** 按钮。
2. 在登录页面输入手机号码。
3. 点击图形验证码图片可刷新验证码，输入图中显示的字符。
4. 点击 **获取短信验证码**，系统将向您的手机发送 6 位数字验证码。
5. 输入收到的短信验证码。
6. 点击 **登录** 按钮。
7. 若为首次登录，系统将自动注册并创建账户，登录后自动跳转至主页。
8. 若已有账户，验证通过后直接进入主页。

### 注意事项

- 图形验证码区分大小写，请准确输入。
- 短信验证码有效期为 5 分钟，过期需重新获取。
- 连续输入错误验证码超过 5 次，账户将被临时锁定 15 分钟。
- 请勿将验证码告知他人，平台工作人员不会向您索要验证码。

## 2. 创作标书

### 功能说明

创作标书是 BidPivot 的核心功能。用户上传招标文件后，系统通过 AI 自动解析文件内容，生成标书大纲，经用户确认和编辑后，启动多智能体协作自动生成标书全文。整个过程包含：上传招标文件、选择行业标签、生成大纲、编辑大纲、启动生成五个主要步骤。

### 操作步骤

#### 2.1 上传招标文件

1. 登录后进入主页，点击 **创建标书** 或页面侧边栏中的 **新建标书**。
2. 进入标书创建向导第一步：**上传招标文件**。
3. 点击上传区域或拖拽文件至上传区域，支持 PDF、DOCX、DOC 格式，单文件大小不超过 50MB。
4. 可同时上传多个相关文件（如答疑补充文件、技术规格书等）。
5. 系统自动解析上传文件，提取关键信息（项目名称、预算、截止时间、评分标准等）。
6. 解析完成后，页面展示提取的关键信息摘要，请核实是否准确。

#### 2.2 选择行业标签

1. 进入向导第二步：**选择行业标签**。
2. 系统根据招标文件内容智能推荐行业标签。
3. 从推荐标签中选择适用项，也可手动搜索并添加其他标签。
4. 行业标签将影响知识库检索范围和写作风格，请尽量选择准确。
5. 确认标签后点击 **下一步**。

#### 2.3 生成大纲

1. 进入向导第三步：**生成大纲**。
2. 点击 **生成大纲** 按钮，系统将基于招标文件内容和评分标准自动生成标书大纲。
3. 生成过程中可实时查看各 Agent 的思考过程和工具调用详情。
4. 大纲生成完毕后，页面展示完整的大纲结构树。

#### 2.4 编辑大纲

1. 在大纲预览页面，可进行以下调整：
   - **拖拽排序**：按住章节条目上下拖拽调整顺序。
   - **添加章节**：点击章节末尾的 **+** 按钮添加新章节，输入章节标题和简要描述。
   - **删除章节**：点击章节右侧的删除图标移除不需要的章节。
   - **编辑描述**：点击章节条目，修改章节的写作要求和描述内容。
   - **折叠/展开**：点击章节前的箭头可折叠或展开子章节。
2. 调整完成后点击 **确认大纲**。

#### 2.5 启动生成

1. 大纲确认后，进入 **启动生成** 页面。
2. 页面展示生成配置摘要（章节数量、预计时间、知识库来源等）。
3. 可选择生成模式：
   - **快速模式**：所有章节串行生成，适合对质量要求不高的场景。
   - **标准模式**：多 Agent 并行写作，效率和质量平衡（推荐）。
   - **精细模式**：增加检查 Agent 和润色步骤，质量最高，耗时较长。
4. 点击 **开始生成**，系统进入生成流程。
5. 生成过程中可通过页面实时查看进度：
   - 整体进度百分比
   - 各章节的生成状态（等待中、生成中、已完成）
   - Agent 思考链和工具调用详情（自动折叠已完成部分）
   - 共享变量（如锁定的价格数据）状态
6. 生成完成后，系统通过页面通知提醒用户，可直接进入编辑页面。

### 注意事项

- 上传的招标文件应尽量完整，包含评分标准的文件有助于生成更高质量的标书。
- 大纲编辑阶段建议仔细核对，生成后再修改会消耗更多时间。
- 生成过程中请勿关闭页面，否则可通过「我的标书」重新进入继续查看进度。
- 关键数据（价格、人员资质、版权信息）如无法从知识库或上传文件中获取，将标记为 **【待人工填写】**，需手动补充。

## 3. 标书编辑

### 功能说明

标书生成完成后，用户可使用内置的 Tiptap 富文本编辑器对内容进行精细编辑。编辑器支持常规排版操作、数字来源高亮显示、实时保存等功能。

### 操作步骤

#### 3.1 打开编辑器

1. 生成完成后，在生成结果页面点击 **编辑标书**。
2. 也可在「我的标书」列表中找到对应标书，点击 **编辑** 进入。
3. 编辑器左侧显示标书大纲导航树，右侧为编辑区域。

#### 3.2 使用 Tiptap 编辑器

1. **文字编辑**：直接在编辑区域点击即可输入和修改文字。
2. **格式设置**：
   - 选中文字后弹出浮动工具栏，支持加粗、斜体、下划线、字体颜色等。
   - 顶部工具栏提供标题级别（H1-H4）、有序/无序列表、引用、对齐方式等。
3. **表格操作**：点击工具栏中的表格图标插入表格，支持合并/拆分单元格、调整列宽。
4. **图片插入**：点击工具栏中的图片图标，上传本地图片或输入网络图片地址。
5. **分页预览**：点击工具栏中的分页图标，可预览文档打印效果。

#### 3.3 数字高亮

1. 标书生成过程中，系统会自动为内容中的关键数字（如价格、工期、百分比等）添加来源标记。
2. 被标记的数字在编辑器中以 **黄色高亮** 显示。
3. 将鼠标悬停在高亮数字上，弹出浮窗显示数据来源（来自哪份上传文件或知识库文档）。
4. 若发现数字有误，可直接点击修改，系统将自动移除来源标记。
5. 导出文档时，所有高亮标记将被自动移除，仅保留数字内容。

#### 3.4 保存

1. 编辑器默认 **自动保存**，每 30 秒自动保存一次当前内容。
2. 页面右上角显示最后保存时间和保存状态（已保存/保存中/保存失败）。
3. 也可按 **Ctrl + S**（Mac 为 **Cmd + S**）手动触发即时保存。
4. 每次保存均会生成版本快照，可在版本历史中查看和恢复。

### 注意事项

- 编辑器支持撤销/重做操作（Ctrl+Z / Ctrl+Shift+Z）。
- 高亮的数字来源标记仅用于编辑参考，导出时会被自动剥离，不影响最终文档格式。
- 长时间未操作（超过 30 分钟），编辑连接可能断开，页面会提示重新加载。
- 多人协作场景下（如未来支持），编辑冲突以最后保存的版本为准。

## 4. 对话式修改

### 功能说明

BidPivot 支持通过自然语言对话对标书内容进行修改。用户可以选中特定文字进行局部修改，也可以发送全局指令对整篇标书进行调整。系统会记录所有修改历史，支持版本对比和回滚。

### 操作步骤

#### 4.1 选中文字修改

1. 在编辑器中选中需要修改的文字内容。
2. 选中后弹出浮动菜单，点击 **AI 修改** 按钮。
3. 右侧弹出对话面板，已自动填入选中的文字内容作为上下文。
4. 在输入框中输入修改指令，例如：
   - "把这段话改得更正式一些"
   - "精简到 200 字以内"
   - "加入我们公司的技术优势描述"
   - "按照评分标准重新组织这段内容"
5. 点击 **发送**，AI 将根据指令生成修改建议。
6. 修改结果以 **对比视图** 展示，左侧为原文，右侧为修改后内容，差异部分高亮标出。
7. 确认修改后点击 **应用**，修改内容将替换原文。若不满意可点击 **重新生成** 或 **放弃**。

#### 4.2 全局指令

1. 在对话面板中，不选中任何文字，直接输入全局指令。
2. 常用全局指令示例：
   - "检查全文的格式一致性"
   - "将所有人称从'我方'改为'本公司'"
   - "增加一段售后服务承诺章节"
   - "将技术方案部分的篇幅压缩 30%"
   - "检查是否有遗漏的评分项"
3. AI 将分析全文并给出修改方案，按章节逐条展示修改建议。
4. 用户可逐条确认或拒绝修改，也可一键全部应用。

#### 4.3 版本历史

1. 点击编辑器右上角的 **版本历史** 图标。
2. 左侧面板展示所有保存版本，按时间倒序排列，每个版本标注修改来源（手动编辑/AI 修改/自动保存）。
3. 点击任意版本可预览该版本的完整内容。
4. 选择两个版本后点击 **版本对比**，以差异高亮视图展示两个版本之间的所有改动。
5. 确认需要回滚时，点击目标版本旁的 **恢复此版本**，当前内容将被替换为该版本。
6. 恢复操作本身也会生成新的版本记录，不会丢失任何历史。

### 注意事项

- 对话式修改会消耗 AI 调用额度，复杂指令（如全文修改）消耗较多。
- AI 修改结果需人工确认后才会生效，系统不会自动覆盖原有内容。
- 版本历史长期保留，不会自动清理。如需删除特定版本，可联系管理员操作。
- 修改指令越具体，AI 生成的结果越准确。建议提供清晰的修改要求和上下文。

## 5. 导出文档

### 功能说明

标书编辑完成后，可导出为 DOCX 或 PDF 格式。系统提供多种导出模板，自动处理排版、目录、页眉页脚、数字来源标记清理等工作，确保输出文档符合招标规范。

### 操作步骤

1. 在编辑器页面或「我的标书」列表中，点击 **导出** 按钮，弹出 AModal 配置对话框。
2. 选择导出格式：
   - **DOCX**：适合进一步手动微调的场景，兼容 Microsoft Word 和 WPS。
   - **PDF**：适合直接提交的场景，格式固定不可修改。
3. 选择导出模板：
   - **标准模板**：通用商务标书排版，适合大多数招标项目。
   - **政府采购模板**：符合政府采购文件格式要求。
   - **自定义模板**：使用管理员预设的自定义模板（需在系统设置中配置）。
4. 配置导出选项：
   - **封面信息**：填写或确认项目名称、投标单位、日期等封面信息。
   - **目录生成**：选择是否自动生成目录及目录层级深度。
   - **页眉页脚**：设置页眉文字（如项目编号）和页脚页码格式。
   - **附录处理**：选择是否包含附录内容及附录排列顺序。
5. 点击 **开始导出**，系统自动执行以下处理：
   - 剥离所有数字来源高亮标记，保留内容。
   - 应用选定模板的排版样式。
   - 生成目录和页码。
   - 渲染最终文档。
6. 导出完成后，页面弹出下载提示，点击 **下载** 保存到本地。
7. 导出的文件同时保存在「我的标书」的导出记录中，30 天内可重复下载。

### 注意事项

- 导出前建议先完整预览标书内容，确保所有【待人工填写】标记已处理。
- PDF 格式不支持后续编辑，如需修改请导出 DOCX 格式后调整。
- 大型标书（超过 100 页）导出可能需要 1-2 分钟，请耐心等待。
- 自定义模板需由管理员在「系统设置」中上传和配置。

## 6. 我的标书

### 功能说明

「我的标书」页面集中管理用户创建的所有标书项目，提供列表查看、搜索筛选、继续编辑、继续对话、删除等操作。

### 操作步骤

#### 6.1 列表管理

1. 点击侧边栏中的 **我的标书** 进入列表页面（使用 ATable 组件展示列表）。
2. 列表默认按最后修改时间倒序排列，展示以下信息：
   - 标书名称
   - 项目状态（草稿/生成中/已完成/已导出）
   - 创建时间
   - 最后修改时间
   - 行业标签
3. 支持按名称搜索和按状态、行业标签筛选（使用 ASelect 下拉选择器）。
4. 支持切换列表视图和卡片视图。
5. 底部使用 APagination 分页组件，支持翻页和每页条数设置。

#### 6.2 继续对话

1. 在标书列表中找到目标标书。
2. 点击 **继续对话** 按钮，进入对话式修改界面。
3. 系统自动加载该标书的历史对话记录。
4. 可继续发送修改指令，AI 将基于当前标书内容进行修改。

#### 6.3 继续编辑

1. 在标书列表中找到目标标书。
2. 点击 **编辑** 按钮，直接进入标书编辑器。
3. 编辑器加载最新的标书内容，可继续修改。

#### 6.4 删除标书

1. 在标书列表中找到目标标书。
2. 点击标书右侧的 **更多操作** 图标，选择 **删除**。
3. 系统弹出 AModal.confirm 确认对话框，提示删除后不可恢复。
4. 确认删除后，标书及其相关的对话记录、版本历史、导出文件将被永久删除。

### 注意事项

- 删除操作不可撤销，请谨慎操作。建议先导出备份再删除。
- 处于「生成中」状态的标书无法删除，需等待生成完成或取消生成后再操作。
- 每个用户默认最多保留 100 份标书，超出后需删除旧标书才能创建新标书。

## 7. 知识库管理

### 功能说明

知识库是 BidPivot 标书生成质量的核心保障。系统支持私有知识库和全局知识库两种类型。私有知识库按用户隔离，仅本人可见；全局知识库由管理员维护，所有用户共享。知识库中的文档经过向量化处理后，可在标书生成过程中被 AI 检索引用。

### 操作步骤

#### 7.1 创建知识库目录

1. 点击侧边栏中的 **知识库** 进入知识库管理页面。
2. 点击 **新建目录** 按钮。
3. 输入目录名称（如"公司资质文件"、"技术方案模板"、"历史标书案例"等）。
4. 选择目录类型：
   - **私有目录**：仅自己可见，适合存放公司内部资料。
   - **全局目录**：所有用户可见（需管理员权限）。
5. 点击 **确认创建**。

#### 7.2 上传文档

1. 在知识库目录列表中，点击目标目录进入。
2. 点击 **上传文档** 按钮（使用 AUpload 组件），或直接拖拽文件到上传区域。
3. 支持的文件格式：PDF、DOCX、DOC、TXT、XLSX、XLS，单文件不超过 20MB。
4. 可批量上传多个文件。
5. 上传完成后，系统自动执行以下处理：
   - 文档解析：提取文本、表格、图片描述等内容。
   - 文本分段：将长文档按语义切分为多个段落。
   - 向量化：对每个段落生成向量嵌入并存储到向量数据库。
6. 处理状态显示在文档列表中：
   - **处理中**：文档正在解析和向量化。
   - **已完成**：文档已可被 AI 检索。
   - **处理失败**：文档格式不支持或内容无法解析，可重新上传。

#### 7.3 管理知识库文档

1. 在目录中可对已上传的文档进行管理：
   - **查看**：预览文档内容和解析结果。
   - **重新处理**：对处理失败或需要更新的文档重新执行向量化。
   - **删除**：从知识库中移除文档及其向量数据。
2. 可对目录进行重命名和删除操作。
3. 删除目录时，目录下的所有文档将一并删除。

#### 7.4 向量化检索

1. 在知识库页面顶部的搜索框中输入关键词或自然语言问题。
2. 系统基于向量相似度检索最相关的知识片段。
3. 搜索结果展示匹配的知识片段、来源文档、相关度评分。
4. 搜索结果可用于：
   - 验证知识库内容是否正确覆盖所需信息。
   - 在创作标书前预先检查可用的参考资料。
   - 评估是否需要补充更多文档到知识库。

### 注意事项

- 上传的文档应尽量清晰完整，扫描件或图片 PDF 的解析效果可能较差。
- 文档向量化通常需要 1-5 分钟，大型文档可能更长，请耐心等待。
- 私有知识库的数据完全隔离，其他用户无法访问，请放心上传敏感资料。
- 全局知识库由管理员维护，普通用户仅可查看和检索，不可上传或删除。
- 知识库容量默认为每个用户 500 个文档，如需扩容请联系管理员。

## 8. 竞品分析

### 功能说明

竞品分析功能帮助用户了解竞争对手的投标策略和优势，为制定差异化竞争方案提供数据支撑。用户可以管理竞品公司信息、上传竞品资料，系统将基于已有数据生成对比分析报告。

### 操作步骤

#### 8.1 竞品公司管理

1. 点击侧边栏中的 **竞品分析** 进入竞品分析页面。
2. 点击 **添加竞品** 按钮。
3. 填写竞品公司基本信息：
   - 公司名称（必填）
   - 简介
   - 主营业务领域
   - 所在地区
4. 点击 **保存** 完成添加。
5. 在竞品列表中可编辑或删除已添加的竞品公司。

#### 8.2 上传竞品资料

1. 在竞品公司详情页面，点击 **上传资料** 按钮（使用 AUpload 组件）。
2. 上传该竞品的相关资料，如：
   - 历史中标公告
   - 竞品产品手册或技术白皮书
   - 公开的投标文件（如有）
   - 行业分析报告中涉及该公司的内容
3. 支持的格式：PDF、DOCX、TXT，单文件不超过 20MB。
4. 上传的资料将自动进行解析和向量化，便于后续检索和分析。

#### 8.3 差异化分析

1. 在竞品分析页面，点击 **生成分析报告** 按钮。
2. 选择要分析的目标项目（从已创建的标书中选择）。
3. 选择要对比的竞品公司（可多选）。
4. 系统基于以下数据生成差异化分析报告：
   - 竞品公开资料中的优势和劣势
   - 当前标书的技术方案和报价策略
   - 行业通用评分标准
5. 分析报告包含：
   - 各竞品的优势和劣势对比表
   - 我方的差异化竞争建议
   - 评分标准中容易拉开差距的关键点
   - 建议突出展示的核心优势
6. 分析报告可保存到知识库，供后续标书创作引用。

### 注意事项

- 竞品资料越多越全面，分析报告的质量越高。
- 分析报告仅供参考，实际投标策略请结合项目具体情况制定。
- 已保存到知识库的分析报告会在相关标书生成时被自动检索引用。

## 9. 丢标分析

### 功能说明

丢标分析帮助用户复盘未中标项目，通过分析评标结果了解失分原因，总结经验教训，并将分析结论保存到知识库以改进后续标书质量。

### 操作步骤

#### 9.1 上传评标结果

1. 点击侧边栏中的 **丢标分析** 进入丢标分析页面。
2. 点击 **新建分析** 按钮，弹出 AModal 对话框。
3. 选择对应的标书项目（从「我的标书」中关联选择，使用 ASelect 下拉选择器）。
4. 使用 AUpload 上传评标结果文件：
   - 评标报告或中标公告（PDF/DOCX 格式）
   - 各投标人得分明细表（如有）
   - 专家评审意见（如有）
5. 系统自动解析评标结果，提取各投标人的得分和排名信息。

#### 9.2 查看分析报告

1. 解析完成后，系统自动生成丢标分析报告，包含：
   - **总分对比**：我方与中标方及各投标方的总分和各项得分对比。
   - **失分项分析**：逐项分析我方失分的评审指标，标注失分幅度和可能原因。
   - **优势项确认**：指出我方得分较高的评审项，确认核心竞争力。
   - **改进建议**：基于失分分析给出具体的改进方向和建议。
2. 分析报告以可视化图表和文字说明结合的方式展示。
3. 可对分析结果进行标注和批注，记录团队讨论结论。

#### 9.3 保存到知识库

1. 在分析报告页面，点击 **保存到知识库** 按钮。
2. 选择目标知识库目录（建议创建专门的"丢标分析"目录）。
3. 系统将分析报告中的关键结论和改进建议保存为知识库文档。
4. 后续创作标书时，AI 将自动检索相关丢标分析结论，避免重复犯错。

### 注意事项

- 评标结果文件的质量直接影响分析准确性，请尽量上传完整的评标报告。
- 分析结论仅供复盘参考，同一项目可能因评标专家不同而有不同侧重点。
- 建议定期回顾丢标分析报告，持续优化投标策略和标书质量。
- 保存到知识库的分析结论将被所有相关标书生成时检索引用。

## 10. 系统设置（管理员）

### 功能说明

系统设置仅对管理员角色开放，提供模型配置、用户管理和审计日志三大功能模块。管理员可通过此页面配置 AI 模型参数、管理系统用户、查看操作审计记录。

### 操作步骤

#### 10.1 模型配置

1. 使用管理员账号登录后，点击侧边栏中的 **系统设置**。
2. 使用 ATabs 标签页组件切换到 **模型配置** 标签页。
3. 配置 LLM 模型：
   - **模型提供商**：选择本地模型或云端模型（如 OpenAI、文心一言、通义千问等）。
   - **API 地址**：填写模型服务的 API 端点地址。
   - **API 密钥**：填写对应的 API Key（云端模型必填，本地模型视部署方式而定）。
   - **默认模型**：设置系统默认使用的模型名称。
   - **备用模型**：设置主模型不可用时的自动切换备选模型。
4. 配置模型参数：
   - **温度（Temperature）**：控制生成随机性，范围 0-2，默认 0.7。标书写作建议 0.3-0.5。
   - **Top-P**：控制词汇采样范围，范围 0-1，默认 0.9。
   - **最大 Token 数**：单次生成的最大长度限制。
   - **上下文窗口大小**：模型可处理的最大上下文长度。
5. 配置嵌入模型（用于知识库向量化）：
   - 嵌入模型提供商和 API 地址
   - 嵌入维度设置
6. 点击 **保存配置**。可点击 **测试连接** 验证配置是否正确。

#### 10.2 用户管理

1. 使用 ATabs 切换到 **用户管理** 标签页。
2. 使用 ATable 查看系统中所有注册用户的列表，展示信息包括：
   - 用户 ID
   - 手机号
   - 注册时间
   - 最后登录时间
   - 角色（普通用户/管理员）
   - 状态（正常/禁用）
3. **修改用户角色**：点击用户行的角色列，可将普通用户提升为管理员或降级。
4. **禁用/启用用户**：点击用户行的状态切换按钮，禁用后该用户将无法登录。
5. **重置用户密码**：点击操作列中的 **重置**，系统将发送新的验证码到用户手机。
6. 支持按手机号搜索和按角色、状态筛选用户。

#### 10.3 审计日志

1. 使用 ATabs 切换到 **审计日志** 标签页。
2. 使用 ATable 查看系统操作的完整审计记录，记录内容包括：
   - 操作时间
   - 操作用户
   - 操作类型（登录/创建标书/导出文档/修改配置/用户管理等）
   - 操作详情（具体操作内容和参数）
   - 操作 IP 地址
   - 操作结果（成功/失败）
3. 支持按时间范围、操作类型、操作用户进行筛选。
4. 支持导出审计日志为 CSV 文件，便于存档和审计。
5. 审计日志默认保留 180 天，超过期限的记录将自动归档。

### 注意事项

- 模型配置变更将立即生效，正在生成中的任务不受影响，新任务将使用新配置。
- API 密钥属于敏感信息，保存后页面仅显示部分掩码，请妥善保管完整密钥。
- 禁用用户后，该用户当前的登录会话将立即失效，所有进行中的任务将被挂起。
- 审计日志不可删除或修改，确保操作记录的完整性和可追溯性。
- 建议定期检查审计日志，及时发现异常操作。
- 管理员应谨慎操作，误修改模型配置可能影响所有用户的标书生成质量。

## 附录：常见问题

### Q: 生成过程中页面断开连接怎么办？

A: 无需担心，生成任务在后台持续运行。重新打开页面后，进入「我的标书」找到对应项目即可查看最新进度。

### Q: 标书中出现【待人工填写】标记是什么意思？

A: 这表示系统未能从知识库或上传文件中找到该数据项的来源（如具体价格、人员姓名等），需您手动填写。请查找相关资料后补充。

### Q: 如何提高标书生成质量？

A: 建议从以下方面优化：
1. 上传完整且清晰的招标文件，包含评分标准。
2. 完善知识库，上传公司资质、历史标书、技术方案等资料。
3. 仔细编辑大纲，确保章节结构和描述准确。
4. 选择合适的行业标签。
5. 参考丢标分析的改进建议。

### Q: 支持同时生成多份标书吗？

A: 支持。系统允许多个标书生成任务并行执行，但同时运行的任务数量受系统资源限制。如遇到任务排队，请耐心等待。

### Q: 知识库中的文档会泄露给其他用户吗？

A: 不会。私有知识库按用户 ID 严格隔离，其他用户无法访问。全局知识库由管理员统一管理，仅包含公共参考资料。
